# Data and State Model: SPEC-015

**Status:** Draft contract model. These are transient/runtime DTOs, not a database schema or migration proposal.

## SearchCapabilityState

| Field | Type | Rule |
| --- | --- | --- |
| `enabled` | boolean | Defaults `false`; server configuration only. A true flag does not override DEC-001, DEC-006, DEC-010, or DEC-012. |
| `policyState` | `allowed | disabled | access_blocked | disclosure_pending | runtime_unavailable` | Unknown or missing state denies the external request. |
| `policyVersion` | bounded identifier or null | Server-authored and auditable; no model-selected value. |

## PublicSearchRequest

| Field | Type | Rule |
| --- | --- | --- |
| `requestId`, `correlationId` | opaque server-generated IDs | Not authorization tokens. Never accept caller IDs as authoritative. |
| `query` | bounded string | Public query only, validated by the server. No FlowZenit-derived fields while DEC-006 is pending. Exact character limit remains unresolved. |
| `queryClass` | `current_public_information | internal_product_data | mixed_or_sensitive | unsupported` | Only `current_public_information` can reach the provider; other classes deny or route to the owning internal tool. |
| `requestedByTool` | registered tool ID/version | Must resolve through SPEC-002; not arbitrary model text. |
| `policyVersion` | bounded identifier | Captures server policy used for decision. |

## ExternalSource

| Field | Type | Rule |
| --- | --- | --- |
| `sourceRef` | per-response opaque ID | Generated by adapter; scoped to the result set, not a durable identity. |
| `title`, `snippet` | bounded strings | Untrusted display content; escaped at the UI boundary and excluded from policy instructions. |
| `url` | validated URL | HTTP(S) only; no credentials or unsafe schemes; exact hostname restrictions remain a future policy choice. |
| `providerPublishedAt` | optional timestamp/text | Preserve only if supplied and parseable; do not fabricate. |
| `retrievedAt` | timestamp | Server-observed time. |
| `rank` | positive integer | Provider ordering only; not confidence or truth. |

## ExternalSearchOutcome

`completed | empty | denied | disabled | timed_out | rate_limited | provider_failed | malformed | partial`

Carries `correlationId`, safe provider category, `sources[]`, and a bounded `limitations[]`. It never contains raw HTTP headers/body, API key, full conversation state, tool permissions, or an assertion that an external claim is verified FlowZenit data.

## SearchAuditEvent (SPEC-010-owned persistence)

Proposed event input contains event/correlation references, policy version, query class, outcome category, source count, provider category, elapsed time, and optionally an approved one-way query fingerprint. It contains no raw query or snippet by default. Persisted retention, fingerprint approval, and field scope depend on DEC-005/006; SPEC-015 does not create its own event table/store.

## State transitions

`proposed -> classified -> policy_checked -> (denied | provider_requested) -> (completed | empty | partial | timed_out | rate_limited | provider_failed | malformed) -> sanitized_response`

Any missing gate, invalid input, redaction failure, unknown provider shape, or correlation failure transitions to a denial/degraded outcome before composing an unsupported answer. Results cannot transition into mutation capability or grant access to internal records.
